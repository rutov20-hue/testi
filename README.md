# My Travel Diary - Дневник путешествий

Современный веб-сайт дневника путешествий с фотографиями и впечатлениями из разных уголков мира.

## 🚀 Особенности

### Функциональность
- ✅ Интерактивная карта мира с маркерами посещенных мест
- ✅ Галерея фотографий с детальными описаниями путешествий
- ✅ Многоязычная поддержка (Русский, English, Română)
- ✅ Темная и светлая темы
- ✅ Система отзывов с возможностью добавления пользовательских отзывов
- ✅ Адаптивный дизайн для всех устройств
- ✅ Анимации при прокрутке
- ✅ Кнопка быстрого возврата наверх

### Оптимизация производительности
- ✅ **SEO-оптимизация**: мета-теги, структурированные данные, sitemap.xml
- ✅ **Кэширование**: Service Worker для оффлайн работы
- ✅ **Сжатие**: GZIP сжатие статических файлов
- ✅ **Ленивая загрузка**: изображения загружаются по мере необходимости
- ✅ **Предзагрузка**: критические ресурсы загружаются приоритетно
- ✅ **PWA**: поддержка Progressive Web App
- ✅ **Аналитика**: мониторинг производительности в реальном времени
- ✅ **Оптимизация шрифтов**: системные шрифты с быстрым отображением

## 📊 Мониторинг производительности

Сайт включает встроенную систему мониторинга:

### Core Web Vitals
- **LCP** (Largest Contentful Paint) - время загрузки основного контента
- **FID** (First Input Delay) - время отклика на первое взаимодействие
- **CLS** (Cumulative Layout Shift) - стабильность макета

### Метрики загрузки
- DNS lookup время
- TCP соединение
- Время запроса/ответа
- DOM загрузка
- Полная загрузка страницы

### Просмотр метрик
Откройте консоль браузера и выполните:
```javascript
// Получить текущий отчет о производительности
performanceMonitor.getReport()

// Получить аналитические данные
getAnalyticsReport()
```

## 🚀 Запуск проекта

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
